# 财报自动更新

`Watch All Company Earnings` 全年全天每 5 分钟检查 `COMPANY_SOURCES` 中的全部公司。它一次读取 Earnings-Image-Studio 已发布的数据，按股票代码匹配公司，并用相同的官方附件解析器独立检查本平台自己的公司列表，覆盖仅在本平台跟踪的公司。

同步只更新新季度或新披露的当前季度，保留历史数值。美元以外的报表必须完成汇率转换才能写入；累计数据不能当成单季度。无法解析的公告会转向其他财务来源，仅刷新当前及新季度，再核对最新财报是否确实写入。现金流按更新公司增量补齐，未披露值不估算。

每天的完整财务、价格、市值和历史现金流刷新继续保留。两条更新任务共用并发锁，避免同时写入数据。有效数据提交后显式发布 Pages，并读取公开数据核对。数据脚本的版本由内容哈希更新，避免页面继续使用旧缓存。

失败不阻断其他公司的有效更新，但最终任务会标为失败并保留逐公司诊断。GitHub 通知是否发送邮件取决于账户的 Actions 通知设置。`Earnings Scheduler Watchdog` 每半小时及发布/刷新完成后检查是否漏掉了定时任务，并在需要时补触发。

5 分钟是巡检配置，不是发布时延保证。GitHub 调度、发行人数据开放时间和源站可用性仍会影响完成时间；新报表版式可能需要维护。没有取得可验证的新值时保持旧的有效数据并报告问题。
